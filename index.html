01 / THE PROJECT

A small tool for following the prices you choose.

Instead of watching charts all day, add an asset, set a price condition, and let a scheduled backend check it for you. The app keeps your list, entry and target prices, and notes together in one place.

It supports stocks and selected cryptocurrencies. The PWA works across desktop and mobile and can be installed from a compatible browser.

02 / WHAT IT DOES
A

Keep a watchlist

Track the tickers you care about, with an entry idea, target price, and a short note about your thesis.

B

Set price conditions

Create alerts for prices moving above or below a level, then review active and triggered alerts in the app.

C

Get a nudge

Scheduled Firebase functions check configured price providers and send alert messages to the Telegram destination set by the operator.
